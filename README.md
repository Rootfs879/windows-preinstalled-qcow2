Pre-installed Windows QCOW2 images for virtualization environments such as QEMU, KVM, libvirt, Proxmox, and virt-manager.

## Features
- Pre-installed Windows
- QCOW2 format
- x86 and x86_64 support
- VirtIO drivers included
- Released by Windows version

## Download
Visit the Releases page to download the image you need:

https://github.com/Rootfs879/windows-preinstalled-qcow2/releases

## Run in virt-manager
1. Open virt-manager
2. Click "Create a new VM"
3. Choose "Import existing disk image"
4. Select the QCOW2 file
5. Set OS to Windows
6. Finish setup and start the VM

## Releases
